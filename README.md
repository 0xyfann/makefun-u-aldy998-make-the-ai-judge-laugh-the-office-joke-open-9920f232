A one-line office joke for "Make the AI Judge Laugh: the Office Joke Open".

`main.py` (Python stdlib only) writes a single original office joke to
`entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

The joke:

> I hit reply-all to say 'please remove me from this thread' and now 400 people are removing me, one email at a time.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
